# Calcito V3

`calcito-football.png` est un visuel original réellement généré pour cette version, à fond transparent : robot footballistique noir, bleu et blanc, ballon, brassard et crampons.

Les variantes accueil, analyse, comparaison, réussite, erreur et vide utilisent actuellement cette même pose avec des messages différents. Il n’existe pas d’autres fichiers de poses supposés. Ajouter de nouveaux visuels réels ici et mettre à jour `mascotImages` dans `src/components/CalcitoMascot.jsx` lorsqu’ils seront fournis ou créés.
